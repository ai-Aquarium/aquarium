# Plan — PR5: Plan step (projects detail redesign)

Design: `docs/design/projects-detail-redesign/` — frame "Project detail —
Plan step" (mocked up in #1134; built alongside PR4 per the user's call).
Fifth PR after spine (#1135), Runs (#1136), Start run (#1137), Requirements
doc (#1140).

## What

`plan/PlanStep.tsx` — the active playbook revision as the mockup shows it,
two-column with the shared `VersionRail` from PR4:

- **Out-of-date banner** — amber `!` card when requirements changes
  landed after `active.activated_at` (real comparison via `GET /changes`
  timestamps; the "from Req v5" lineage isn't stored so the count stands
  in). `See changes` → Requirements doc; `Update plan` opens the editor.
- **Toolbar** — `Plan` + `v{rev}` pill + provenance
  (`created_by === "agent" ? "Generated by agent" : "Created by {who}"` +
  relative `activated_at`), `Steps | Diff v{p} → v{c}` toggle,
  `Edit`, `Make cards`.
- **Step rows** — number, title, body, meta line: assignee `Pill` +
  `Why: {assignee_reason}` + `Needs approval` pill on `checkpoint` steps.
- **Diff view** — `planDiff(previous.steps, active.steps)` → existing
  `PlanDiffView`.
- **Edit** — reveals the full `PlanPanel` (draft-with-agent, step
  editing, activation) below the doc; all existing machinery kept.
- **Make cards** — navigates to the Cards step (`onNavigate("board")`).
- **Versions rail** — every revision desc (`Current` on active, author,
  `activated_at`, `note` or "{n} steps"); **USED BY** groups history runs
  by their pinned `playbook_rev` ("Runs R6, R7 used v3") — real data.

## Approximations

- Per-step **source chips** skipped — steps don't record which inputs
  they use.
- "Make cards" navigates rather than generates (cards mint at run start).
- No `from Req v{N}` suffix in version rows — lineage not stored.
- `PlanTab` deleted; `TAB_COMPONENT.plan` points at `PlanStep`.
